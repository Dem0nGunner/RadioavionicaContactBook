Проект цифровой записной книжки для предприятия АО "Радиоавионика", созданный в рамках производственной практики.
Выгруженная сборка представляет собой 2 части:
- Коды;
- Загрузчик.

Коды входящих в сборку файлов можно посмотреть в папке Zapisnaya.
!Скачанная полностью сборка с git может не запускаться и является только демонстрацией кода.
При необходимости запустить проект наглядно советую использовать Загрузчик 

->CallBookInstaller.msi<-

Проект представляет собой простой интерфейс для работы с таблицами Exel, объединяя их в небольшую БД.
Интерфейс разработан на основе нужд работников предприятия.
Краткую и наглядную инструкцию по работе в приложении можно найти после запуска по кнопке "Инструкция"

Stack: C# .NET
